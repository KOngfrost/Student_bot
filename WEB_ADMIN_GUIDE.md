# Веб-админка Student Bot - Инструкция по использованию

## 🎉 Что было создано

Полноценная веб-админка для управления ботом студенческого совета с:

- ✅ **Авторизацией** (логин/пароль через сессии)
- ✅ **Дашбордом** со статистикой
- ✅ **Управлением администраторами**
- ✅ **Просмотром заявок** с фильтрами
- ✅ **Базой знаний** для автоответов
- ✅ **FAQ-деревом** для отдела "Информ"
- ✅ **Управлением событиями**
- ✅ **Логами действий**
- ✅ **Docker** сборкой

> **Tailscale** будет добавлен позже для безопасного удалённого доступа.

---

## 🚀 Быстрый старт (локально)

### 1. Установите зависимости

```bash
pip install -r requirements.txt
```

### 2. Запустите веб-сервер

```bash
uvicorn web.main:app --host 0.0.0.0 --port 8000 --reload
```

### 3. Откройте браузер

- URL: `http://localhost:8000`
- Логин: `admin`
- Пароль: `admin123`

---

## 🐳 Запуск через Docker

### 1. Запустите через Docker Compose

```bash
docker-compose up -d --build web-admin
```

### 2. Доступ

- URL: `http://localhost:8000`
- Логин: `admin`
- Пароль: `admin123`

## 🔐 БЕЗОПАСНОСТЬ

### ⚠️ СРОЧНО: измените пароль по умолчанию!

Откройте `web/routes/auth.py` и измените:

```python
ADMINS = {
    "admin": "your_secure_password",  # Замените на свой пароль!
}
```

### Для продакшена

1. **Используйте хэши паролей:**
   ```python
   import bcrypt
   hashed = bcrypt.hashpw(b"your_password", bcrypt.gensalt()).decode()
   # Проверка: bcrypt.checkpw(password.encode(), hashed.encode())
   ```

2. **Включите HTTPS** через reverse proxy (nginx)

3. **Настройте Tailscale** для безопасного удалённого доступа

## 🎯 Функционал

### Дашборд (`/`)
- Общее количество заявок
- Заявки в обработке
- Выполненные заявки
- Новые заявки
- Последние 10 заявок

### Управление администраторами (`/admin/admins/`)
- Добавление новых админов
- Привязка к отделам
- Назначение ролей (admin/superadmin)
- Удаление админов

### Заявки (`/tickets/`)
- Просмотр всех заявок
- Фильтрация по статусу
- Фильтрация по отделу
- Поиск по теме/описанию
- Просмотр деталей заявки

### База знаний (`/knowledge/`)
- Добавление записей (keywords → answer)
- Привязка к отделам
- Удаление записей

### FAQ (`/faq/`)
- Создание FAQ-дерева
- Добавление вопросов и ответов
- Иерархическая структура

### События (`/events/`)
- Создание мероприятий
- Привязка к отделам
- Просмотр регистраций

### Логи (`/logs/`)
- Журнал всех действий
- Экспорт в CSV

## 🆘 Решение проблем

### Не могу войти

1. Проверьте логин/пароль по умолчанию:
   - Логин: `admin`
   - Пароль: `admin123`

2. **Не забудьте изменить пароль!**

### Ошибка подключения к БД

1. Запустите PostgreSQL:
   ```bash
   docker-compose up -d db
   ```

2. Проверьте логи:
   ```bash
   docker logs student_bot_web
   ```

### Веб-админка не загружается

1. Проверьте, что сервер запущен:
   ```bash
   uvicorn web.main:app --host 0.0.0.0 --port 8000 --reload
   ```

2. Откройте браузер: `http://localhost:8000`
