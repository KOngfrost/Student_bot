# Руководство администратора веб-панели

## Вход

Панель доступна по адресу, который выдал вам администратор сервера
(через Tailscale или SSH-туннель, например `http://localhost:8000` при туннеле).

Логин и пароль выдаёт суперадминистратор. Пароль хранится в базе только в виде
хеша — восстановить его нельзя, только сбросить.

**Защита от подбора:** после 5 неудачных попыток входа за 15 минут ваш IP
временно блокируется. Все входы (успешные и нет) фиксируются в журнале.

## Роли

| Роль | Что можно |
|---|---|
| **SUPERADMIN** | Всё: все отделы, передача заявок, управление админами |
| **DEPARTMENT_ADMIN** | Заявки и контент (FAQ, база знаний, события) только своего отдела |
| **VIEWER** | Просмотр всех заявок и журналов, без права изменений |

## Работа с заявками

Раздел **«Заявки»**: поиск, фильтр по статусу и отделу. Админ отдела видит
только заявки своего отдела.

Нажмите **«Открыть»**, чтобы увидеть карточку заявки:

- тема, описание, автор (или «Аноним»), отдел, статус, дата;
- полная история переписки (вопрос студента, ответы, системные события).

### Ответить студенту

В карточке заявки введите текст ответа и нажмите **«Отправить ответ»**.
Ответ:

- сохраняется в истории заявки;
- отправляется студенту в VK автоматически;
- переводит заявку из статуса «Новое» в «В обработке».

Отметка **«Завершить заявку»** дополнительно закрывает заявку (статус «Выполнено»).

### Сменить статус

Доступные переходы:

```
Новое → В обработке → Передано в администрацию СГ → Выполнено → Выполнено (авто)
                    → Передано в Хозчасть      ↗
```

Недопустимые переходы (например, «Выполнено» → «Новое») система отклоняет.

### Передать в другой отдел

Доступно только суперадмину: в карточке заявки выберите отдел и нажмите
**«Передать»**. Заявка получит нового ответственного, событие фиксируется в истории.

## Остальные разделы

- **База знаний / FAQ / События** — контент по отделам; админ отдела видит и меняет только своё.
- **Админы** — управление VK-администраторами (назначать суперадминов может только суперадмин).
- **Логи** — журнал действий, экспорт в CSV.

## Выход

Кнопка **«Выйти»** в левой панели. Сессия также завершается через час
бездеятельности.
